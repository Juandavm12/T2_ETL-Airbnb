# Logs de ejecución

Los logs operativos se crean al ejecutar el proceso ETL, con fecha, hora y
niveles INFO, WARNING y ERROR. Se ignoran en el repositorio; esta carpeta
conserva su documentación y `.gitkeep`.

Para revisar un ejemplo real ya generado, consulta
[el log de carga](../evidencias/carga_real.txt). Es evidencia histórica,
no un log inventado ni una ejecución nueva.
